# 12-р анги · React-ын өмнөх JavaScript сэргээлт (80 минут)

Проектороор харуулах 25 слайдтай интерактив хичээл. Хөтөч зөвшөөрвөл жишээ бүр **жинхэнэ JavaScript**-ээр ажиллана, «Засах» дарж кодыг өөрчилж болно. Зөвшөөрөхгүй үед урьдчилан бэлдсэн гаралт (Chrome-ийн гаралттай ижил) харагдана.

**Нээх:** `index.html`-ийг хөтөч дээр нээнэ. Netlify дээр `/12-js/` хаягаар гарна.
