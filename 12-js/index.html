Арга

БагшидМөр дээр дарвал тухайн хэсэг рүү шилжинэ. Дээд талын шугамын хэсэг бүрийн өргөн нь минуттай пропорциональ. Цаг хоцорвол «Объект», «Модуль» хэсгийг товчил. Массив (map, filter) ба Spread хоёрыг алгасаж болохгүй: React-д хамгийн их хэрэглэгдэнэ.

Энэ React кодыг уншиж чадах уу?

Ойлголт дээр дарвал кодонд хаана байгаа нь тодорно. Хичээлийн төгсгөлд энэ кодын мөр бүрийг тайлбарладаг болно.

БагшидСурагчдаас асуу: «Энэ кодын аль хэсгийг ойлгохгүй байна вэ?» Гараа өргүүлж, хамгийн олон хүн ойлгохгүй байгаа ойлголтыг тэмдэглээд, тухайн хэсэгт илүү цаг гарга. «Бүгдийг» товч бүх ойлголтыг зэрэг тодруулна.

Энэ утга if дотор үнэн үү? Карт дээр дар

БагшидFalsy утга ердөө 6: false, 0, "", null, undefined, NaN. Бусад бүх зүйл truthy, хоосон массив [] ба хоосон объект {} ч truthy! Картуудыг нэг нэгээр нь таамаглуулаад дар.

Богино нөхцөл: ? : && ?? ?.

a ? b : ca үнэн бол b, үгүй бол c.
a && ba үнэн бол b, худал бол a-г өөрийг нь буцаана.
a ?? ba нь null / undefined бол b.
a?.ba байхгүй бол алдаа гаргахгүй, undefined буцаана.
БагшидСүүлийн мөр алдаа гаргана. «?. байгаа ба байхгүй мөрийн ялгаа юу вэ?» гэж асуу. API-аас өгөгдөл ирээгүй үед энэ алдаа React-д хамгийн их гардаг.
