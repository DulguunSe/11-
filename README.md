# 11-р анги · Сонгон хичээл · Python: эхний алхам

Компьютергүй ангид зориулсан 80 минутын хичээл. Багш проектороор харуулж, сурагчид цаасан дээр таамаглаж, мөшгинө. Python-ийг эхнээс нь модуль хүртэл үзнэ.

**Нээх:** `index.html`-ийг хөтөч (Chrome, Edge, Firefox) дээр давхар товшиж нээнэ. Интернэт шаардлагагүй. Интернэттэй үед л тусгай фонт ачаална.

## Удирдлага

| Товч | Үйлдэл |
|---|---|
| `→` `Space` `PageDown` | Дараагийн слайд (презентерийн товчлуур ажиллана) |
| `←` `PageUp` | Өмнөх слайд |
| `N` | Багшийн тэмдэглэл нээх/хаах |
| `F` | Бүтэн дэлгэц |
| `T` | Хичээлийн цаг эхлүүлэх/зогсоох (хэсгийн хугацаа хэтэрвэл улаан болно) |
