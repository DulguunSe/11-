# Төгс шүдний эмнэлэг — вэбсайт, эмнэлгийн систем, AI маркетинг

Өвөрхангай аймгийн Арвайхээр хотын **Төгс шүдний эмнэлэг**-т зориулсан нэгдсэн систем.
Нэг сервер (Node.js + SQLite) дээр гурван хэсэг ажиллана:

| Хэсэг | Хаана | Юу хийдэг |
|---|---|---|
| **Вэбсайт** | `/` | Демо загвараар (цэнхэр→хөх, ногоон, алтлаг ТӨГС лого). Үйлчилгээ, эмч нар, Япон цайруулалт, зөвлөгөө, асуулт хариулт, холбоо барих. **Онлайн цаг захиалга** бодит сул цагаар, эмч сонгох, шүд сонгох, захиалгын дугаар, "Миний захиалсан цагууд"-аас цуцлах. |
| **Эмнэлгийн систем** | `/admin` | Мондентал маягийн: цагийн хуваарь (эмч бүрээр, **давхар цаг бичигдэхгүй**), эмч бүр өөрийн эрхээр нэвтэрч өдрийн захиалгаа харна, үйлчлүүлэгчийн карт (**эмчилгээний түүх огноогоор**, шүдний диаграм, рентген/файл, төлбөр, үлдэгдэл), тайлан (**эмч бүрийн орлого**, үйлчилгээ, төлбөрийн хэлбэр, авлага, CSV), **SMS сануулга** (маргаашийн цаг, захиалгын баталгаа, 6 сарын давтан үзлэг), үйлдлийн түүх, өдөр бүрийн нөөц хуулбар. |
| **AI маркетинг** | `/admin/marketing` | Clicky Vicky маягийн: эмнэлгийн мэдээлэл, өнгө аяс, зургаа нэг оруулбал **AI (Claude) пост бичиж, брэндийн зураг бүтээнэ** → та хянаж засна, батална → **Facebook, Instagram-д хуваарийн дагуу (өдөр бүр / 2 хоног тутам) автоматаар** нийтэлнэ. Пост бүр сайтын захиалгын холбоостой тул постоос ирсэн захиалгыг тайланд тоолно. |

Ажилтны эрх: **Админ** (бүгд), **Эмч** (өөрийн цаг, үйлчлүүлэгчийн түүх, эмчилгээ бүртгэх, өөрийн орлого), **Ресепшн** (цаг, үйлчлүүлэгч, төлбөр, SMS, маркетинг).

Ажилтанд зориулсан гарын авлага: [docs/ГАРЫН_АВЛАГА.md](docs/ГАРЫН_АВЛАГА.md)

## 1. Танилцуулга (демо) ажиллуулах

Node.js 22.13+ хэрэгтэй.

```bash
cd togs-dental
npm install
npm run build
SEED_DEMO=1 INITIAL_ADMIN_PASSWORD=demo-admin-1 npm start
```

- Сайт: http://localhost:3000 · Админ: http://localhost:3000/admin
- `admin` / `demo-admin-1` (анх нэвтрэхэд нууц үг солиулна)
- Жишээ эмч: `emch1`, `emch2` · ресепшн: `reception` · нууц үг `demo12345`
- Жишээ өгөгдлийг арилгах: серверийг зогсоогоод `data/` хавтсыг устгана.

Хөгжүүлэлтийн горим (код өөрчлөхөд шууд шинэчлэгдэнэ): `npm run dev` → http://localhost:5173

## 2. Бодит сервер дээр суулгах (санал болгох арга)

Жижиг VPS (1 vCPU, 1–2 GB RAM, Ubuntu; сард ~$6) хангалттай. Домэйн (жш: `togsdental.mn`) серверийн IP руу A record-оор заасан байх.

```bash
# Сервер дээр (Docker суусан байх)
git clone <энэ репо> && cd <репо>/togs-dental
cp .env.example .env      # DOMAIN, APP_SECRET, INITIAL_ADMIN_PASSWORD, ANTHROPIC_API_KEY бөглөнө
docker compose up -d --build
```

Caddy автоматаар HTTPS гэрчилгээ авч, `https://DOMAIN` дээр сайт нээгдэнэ. Өгөгдөл `togs-data` volume-д хадгалагдана.

Шинэчлэх: `git pull && docker compose up -d --build`

Docker-гүй (ямар ч Node 22 хостинг): `npm ci && npm run build && NODE_ENV=production PUBLIC_URL=https://... npm start` — `data/` хавтас байнга хадгалагдах (persistent disk) ёстой.

## 3. Тохиргоо (орчны хувьсагч)

| Хувьсагч | Тайлбар |
|---|---|
| `PUBLIC_URL` | Сайтын бүтэн хаяг. Пост дахь холбоос, Facebook-ийн preview, Instagram-д заавал (HTTPS). docker-compose-д `DOMAIN`-оос автоматаар. |
| `APP_SECRET` | Facebook токен, SMS түлхүүрийг шифрлэх нууц үг. Тохируулахгүй бол `data/.secret` үүснэ. |
| `INITIAL_ADMIN_PASSWORD` | Анхны `admin` хэрэглэгчийн нууц үг. Хоосон бол санамсаргүй үүсгэж `data/INITIAL_ADMIN_PASSWORD.txt`-д бичнэ. |
| `ANTHROPIC_API_KEY` | AI маркетингийн түлхүүр (console.anthropic.com). Байхгүй бол AI товч идэвхгүй, гараар пост бэлтгэж болно. |
| `CLAUDE_MODEL` | Анхдагч `claude-opus-5-5`. Хямдруулах бол `claude-sonnet-5-5`. |
| `DATA_DIR` | Өгөгдлийн сан, файл, нөөц хуулбарын хавтас (анхдагч `./data`). |
| `PORT` | Анхдагч 3000. |
| `SEED_DEMO` | `1` бол жишээ өгөгдөл нэмнэ (зөвхөн танилцуулгад). |

Эмнэлгийн нэр, утас, хаяг, ажлын цаг, үйлчилгээ, үнэ, ажилтнуудыг **админ хэсгийн Тохиргоо**-ноос өөрчилнө (кодонд хүрэхгүй).

## 4. Анх ажиллуулсны дараа

1. `/admin` → `admin` эрхээр нэвтэрч нууц үгээ солино.
2. **Тохиргоо → Ажилтнууд**: эмч, ресепшнийг нэмнэ (эмч бүр өөрийн нэвтрэх нэр, нууц үгтэй).
3. **Тохиргоо → Үйлчилгээ, үнэ**: үнэ, үргэлжлэх хугацааг засна (одоо демо сайтын 6 үйлчилгээ + "Шүд авах", "Үзлэг" орсон; үнэ 0 = "үзлэгийн дараа").
4. **Тохиргоо → Эмнэлэг**: ажлын цаг, үдийн цай, онлайн захиалгын тохиргоо.
5. **Тохиргоо → SMS**: SMS үйлчилгээгээ холбоно (доор).
6. **AI маркетинг → Холболт**: Facebook хуудас, Instagram (доор).
7. **AI маркетинг → Брэнд**: өмнөх постуудаа оруулж хэв маяг сургана; **Зургийн сан**-д эмнэлгийн зургуудаа нэмнэ.

## 5. Facebook, Instagram холбох

Систем Graph API-аар хуудсанд шууд нийтэлнэ. Нэг удаа тохируулна:

1. developers.facebook.com → **Create App** (Business). Хуудасны админ дансаар.
2. Instagram дансаа Business/Creator болгож Facebook хуудастай холбоно.
3. Graph API Explorer дээр `pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish, business_management` эрхтэй токен үүсгээд Access Token Debugger-ээр урт хугацааных болгоно.
4. `me/accounts` → хуудасны `id`, `access_token`-ийг **AI маркетинг → Холболт**-д оруулна. Систем шалгаж, Instagram дансыг автоматаар олно.

Апп "Development" горимд байхад тухайн апп-д эрхтэй (админ/тестер) хүмүүсийн хуудсанд нийтэлж чадна — эмнэлгийн хуудасны админыг апп-ын Roles хэсэгт нэмбэл хангалттай. Токен шифрлэгдэж хадгалагдана.

## 6. SMS холбох

Монголын аль ч SMS үйлчилгээ (Мобиком, Юнител, Скайтел, MessagePro г.м.)-ний **HTTP API**-г холбоно. **Тохиргоо → SMS**:

- API хаяг: `https://...?...&to={phone}&text={message}` — `{phone}`, `{message}` автоматаар орлуулагдана (POST бол биеийн загвар ба толгой нэмж болно).
- "Кирилл → латин" асаалттай бол SMS хямд (латин 160 тэмдэгт, кирилл 70).
- Мессежийн загварууд: `{clinic} {name} {date} {time} {service} {doctor} {phone} {link}`.
- **Турших** товчоор шалгана. Илгээсэн бүх SMS **SMS** хэсгийн түүхэнд харагдана.

Автомат: маргаашийн цагийн сануулга (тохируулсан цагаас хойш, өдөрт нэг удаа), онлайн захиалгын баталгаа, давтан үзлэг (эмчилгээнээс хойш N сарын дараа).

## 7. AI маркетинг ба зардал

- Пост бичих: Claude (`claude-opus-5-5`, structured output). Нэг пост ойролцоогоор $0.03–0.06; 2 хоног тутам нийтэлбэл сард ~$1–2.
- Зураг: брэндийн 4 загвар (зурагтай, зөвлөгөөний жагсаалт, онцлох, мэндчилгээ) серверт бүтээгдэнэ — нэмэлт төлбөргүй, эмнэлгийн бодит зургийг ашиглана.
- Аюулгүй байдал: AI-д эмнэлгийн дүрэм өгсөн (үр дүнг баталгаа гэж амлахгүй, урамшуулал зохиохгүй). **Батлах шаардлагатай** горим анхдагчаар асаалттай: хүн хянаж байж нийтэлнэ.
- Автомат горим (autopilot): дараагийн N пост үргэлж бэлэн байлгана; хуваарьт цаг болоход зөвхөн батлагдсан пост нийтлэгдэнэ.

## 8. Нөөц хуулбар, аюулгүй байдал

- Өдөр бүр 03:00-д `data/backups/togs-YYYY-MM-DD.db` (сүүлийн 14 хоног). Гараар: `npm run backup`. Мөн VPS-ийн snapshot-ыг долоо хоног тутам авахыг зөвлөе (рентген зургууд `data/uploads/`).
- Нууц үг scrypt-ээр хэшлэгдэнэ, сесс httpOnly cookie, CSRF хамгаалалт, нэвтрэх оролдлогын хязгаар.
- Үйлчлүүлэгчийн файлууд зөвхөн нэвтэрсэн ажилтанд харагдана; карт нээх, засах, устгах бүр **Үйлдлийн түүх**-д бичигдэнэ.
- Хувь хүний мэдээлэл хамгаалах тухай хуулийн дагуу серверт хандах эрхийг хязгаарлаж, HTTPS ашиглана.
- Нууц үгээ мартвал: `npm run create-admin -- admin ШинэНууцҮг123`

## 9. Хөгжүүлэгчид

```
togs-dental/
  index.html, admin.html     вэбсайт ба админы HTML
  src/site/                  вэбсайт (демо загварын CSS, React)
  src/admin/                 админ (React, Tailwind)
  src/shared/                API клиент, формат, төрөл
  server/                    Hono API, SQLite (node:sqlite), хуваарь
    routes/                  public, auth, appointments, patients, admin, marketing, staff
    services/                booking (давхардал), sms, ai (Claude), render (зураг), social (Graph API), posts, scheduler
  assets/fonts/              постын зурагт ашиглах фонт (Onest, Golos Text, Forum — OFL)
  tests/                     API тест (npm test)
```

- `npm test` — 16 тест: захиалга ба давхардал, эрх, түүх, төлбөр, тайлан, файл, SMS сануулга, Facebook/Instagram нийтлэл (туршилтын Graph API), AI хүсэлтийн бүтэц (туршилтын Claude сервер).
- `npm run build` — typecheck + client build + server bundle.
